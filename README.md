# Aesthetic Haven Studio (agentwell.agency)

A high-converting, warm minimalist curation hub & bridge page optimized for US Pinterest traffic.

## 🌿 Aesthetics & Design System
- **Style:** Warm Minimalist Editorial / Modern Aesthetic
- **Colors:**
  - Background: `#FAF8F5` (Soft warm cream)
  - Borders: `#EAE6DF` (Subtle warm taupe)
  - Typography: `#1F1F1F` (Dark charcoal)
  - Earth-tone Badges: Terracotta (`#B85D43`), Sage (`#4A6B5B`), Olive (`#556B2F`), Honey (`#9E7444`)
- **Typography:**
  - Headings: `Playfair Display` (Warm editorial serif)
  - Body & UI: `Plus Jakarta Sans` / `Inter` (Crisp legible sans-serif)

## 📁 Files Included
- **`index.html`**: Zero-dependency, ultra-fast single-page application with Tailwind CSS, responsive filters, Web Share API, newsletter capture, schema.org JSON-LD, and Pinterest Rich Pin OpenGraph meta tags.
- **`AestheticHavenStudio.tsx`**: Modular React / Next.js component ready for Next.js App Router (`app/page.tsx`).
- **`vercel.json`**: Pre-configured Vercel static deployment with security headers and clean URLs.
- **`package.json`**: NPM metadata for previewing with `npx serve .`.

## 🚀 Instant Deployment to Vercel

```bash
cd aesthetic-haven-studio
npx vercel --prod
```
Or connect this directory to a GitHub repository and import directly into Vercel.
